A personal portfolio website documenting my interests, projects, achievements and ongoing journey towards aviation and aerospace engineering. The website brings together my aviation-focused work, technical projects, academic milestones and interests in one place.

## Overview

This portfolio is a static, front-end website built with HTML, CSS and JavaScript. It introduces me and my interests, highlights selected projects, presents certificates and achievements, and provides contact links.

## Website Sections

### Home
A landing section introducing me as an aspiring aviator and aerospace engineer, with links to explore the portfolio.

### About Me
A short introduction to my interests, learning goals, skills and activities beyond aviation.

### Projects
The projects section currently includes:

- **AeroPlanner** — a web-based aircraft performance calculator. The project card links to the separately hosted AeroPlanner website.
- **Air-crash Investigation Project Reports** — case-study reports exploring aviation accidents, contributing factors and investigation findings.
- **Rocket Designing** — an early project exploring rocket concepts, design and physical modelling.
- **Aeromodelling & Workshop** — hands-on learning related to model aircraft and aeromodelling.
- **Aviation Portfolio Website** — this website and its development.
- **Ab Initio Cadet Pilot Selection Preparation** — ongoing personal preparation and study resources.

Some project cards represent work in progress; their descriptions should be updated as the projects develop.

### Achievements
Certificates and milestones are grouped into categories for easier browsing:

- Academic and other achievements
- LogiQids certificates and recognition
- SpellBee certificates and medal
- SOF National Cyber Olympiad

Selecting a certificate image opens the corresponding image in a new browser tab so it can be viewed at a larger size.

### Contact
The contact section includes an email address, location text and a link to my GitHub profile.

## Project Structure

```text
Aviation-Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── a350-bg.jpeg
    ├── anshul-photo.webp
    ├── BITS-Pilani/
    ├── LogiQids/
    ├── Other/
    ├── SOF/
    └── SpellBee/
```

- `index.html` contains the website sections and content.
- `style.css` contains the visual design, responsive rules and presentation styles.
- `script.js` contains the website's client-side interactive behaviour.
- `assets/` contains the background, profile photograph and achievement images. Certificate images are grouped into folders by category.
